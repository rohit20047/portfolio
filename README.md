# Rohit's Portfolio

A personal portfolio website introducing Rohit, showcasing projects, skills, and a bit of his coding journey.

## Sections

- **Hero** – quick intro and tagline
- **About** – a short summary of what he does
- **Skills** – frontend, backend, and tooling skills
- **Projects** – featured work
- **My Journey** – background/timeline
- **Blog** – posts/writing
- **Contact** – ways to get in touch

## Tech stack

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS

## Getting started

```sh
npm i
npm run dev
```

## Available scripts

- `npm run dev` – start the local dev server
- `npm run build` – build for production
- `npm run preview` – preview the production build locally
- `npm run lint` – run ESLint
